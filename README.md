# 링클하우스 소개 홈페이지

`linklehouse.xyz`에 공개되는 한국어 소개 홈페이지입니다. GitHub Pages가 `main` 브랜치의 루트를 배포합니다.

- `index.html`: 홈페이지 문구와 화면 구성
- `style.css`: PC·휴대폰 화면 디자인
- `site.js`: 기능 탭, 메뉴, 예시 흐름과 안내창
- `assets/`: 21번 비취옥 로고와 상품 예시 이미지
- `CNAME`: 현재 도메인. 임의로 삭제하거나 변경하지 않습니다.
- `en/`: 기존 주소의 이동 설정을 유지합니다.

로그인 버튼은 현재 회원 서비스 연결 준비 안내창입니다. 로그인 주소가 준비되면 실제 주소와 연결해야 합니다. 문의 이메일은 `support@linklehouse.xyz`입니다. 예시 화면은 실제 상품 등록을 실행하지 않습니다.

`.com` 사용 준비가 끝나면 GitHub Pages 도메인과 DNS 연결 상태를 확인한 후 `CNAME`, canonical·OG 주소, 이메일·회원 서비스 주소를 함께 검토합니다.
